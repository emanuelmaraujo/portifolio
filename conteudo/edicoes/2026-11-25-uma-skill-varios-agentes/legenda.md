Esta semana coloquei a mesma skill para rodar no Claude, no ChatGPT e no repositório, para agentes como Codex, Cursor e Gemini CLI.
Skill é uma pasta com um arquivo SKILL.md (nome, descrição e instruções) e, se precisar, scripts e guias de apoio. O formato é aberto: o arquivo é o mesmo, o que muda é a pasta onde cada ferramenta procura.
No vídeo mostro como organizei, com uma fonte única e uma cópia sincronizada por script, e o que não viaja junto: o ambiente e os conectores.
Não é guia definitivo, é o que funcionou aqui. As pastas ainda variam entre ferramentas, então vale conferir a documentação de cada uma.
